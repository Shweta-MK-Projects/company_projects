# Revenue Intelligence & Demand Forecasting Demo

This demo project replicates the **Conversational Revenue Intelligence & Demand Forecasting** portfolio described in Shweta M K's resume.

## Project Structure

- `analytics/` – Sample SQL scripts that create a simple star‑schema and a demand‑forecasting view.
- `data_simulation/` – Python script generating synthetic sales and inventory CSV files.
- `dashboards/` – Placeholder Power BI file (`revenue_dashboard.pbix`).
- `README.md` – This documentation.

**How to run**
1. Execute the Python data‑generation script to produce `sales.csv` and `inventory.csv`.
2. Run the SQL script (e.g., in SQLite or SQL Server) to create tables and the `forecast_view`.
3. Open the Power BI file and connect to the generated CSVs to explore the dashboards.

*All files are scaffolds for demonstration purposes; replace the placeholders with real implementations as needed.*
