# Shweta M K - Analytics Portfolio & Project Catalog

Welcome to my portfolio of end-to-end data analytics and business intelligence projects. This workspace is structured as a professional, production-ready code repository showcasing advanced database architectures, analytical query design, predictive analytics pipelines, data visualization specs, and AI integrations.

## Portfolio Directory Architecture

Each project is designed under a standardized enterprise-grade layout:
* `/database` - Relational DDL schemas, indexes, star/snowflake architectures, views, and data storage design.
* `/analytics` - SQL scripts covering recursive CTEs, window functions, statistical models, predictive engines, and AI orchestration.
* `/dashboards` - Configuration code, DAX measures, M script ETL expressions, and Tableau custom LOD parameters.
* `/data_simulation` - Clean Python scripts generating comprehensive synthetic datasets for end-to-end processing.
